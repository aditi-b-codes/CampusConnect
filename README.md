# CampusConnect

A simple student event and club discovery website for VIT Bhopal.

## Features

- Upcoming campus events
- Event search
- Event category filtering
- Club categories
- Event registration form
- Client-side form validation
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## About the Project

CampusConnect is a small web project designed to make it easier for students to discover events and clubs happening on campus.
